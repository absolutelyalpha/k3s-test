How it works: every cluster only resolves its own cluster.local zone, so a peer
service is published locally as a Service whose EndpointSlice holds the peer's
addresses. Headless mode skips kube-proxy entirely, which is what makes it work
on k3s with the nftables proxy mode.

Limits to know: one EndpointSlice has one port, so mirror again under another
name for a second port. Endpoints are static, so re-apply this release when the
peer changes its NodePort or pod IPs (or automate that with a CronJob).
